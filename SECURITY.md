# Security Policy

## Supported Versions

Always update to the latest release. Only the most recent version receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please email [igor@igorkalen.dev](mailto:igor@igorkalen.dev) directly. Do not open a public GitHub issue.

You can expect a response within 48 hours. If the vulnerability is confirmed, a patch will be released as soon as possible and you will be credited in the release notes.
